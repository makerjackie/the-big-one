# 用 AI 纯代码做动画短片：THE BIG ONE 复盘

这份文档记录《THE BIG ONE》是怎么做出来的、哪些做法管用、踩过哪些坑。想自己做一部，直接看最后的提示词（完整版在 [PROMPT.md](PROMPT.md)）。

## 做成了什么

- 39 秒动画短片，13 个镜头，936 帧（24fps），1080p
- **没有任何图像模型、视频模型、音频文件**：画面是 three.js 实时渲染，配乐和音效是 JavaScript 合成的
- 整部片子是一个 716 KB 的 HTML，离线双击就能播；同一份代码也能逐帧导出 MP4
- 约 5800 行代码，26 个源文件
- 分工：Claude Opus 5.5 主 Agent（导演、渲染、建模、动画）+ 2 个并行子 Agent（配乐音效、道具建模）
- 时间：第一版 30 多分钟出片（含配乐）；之后人提了 3 轮意见，Agent 前后实际干活 2 个多小时

## 总体做法

### 1. 先读一个做得好的参考项目，学结构，不抄内容

我们读了 [0xCodez/leviathan](https://github.com/0xCodez/leviathan)（MIT），学它的渲染管线、角色骨骼、云和水花的做法，然后写了一个完全不同的故事和角色。参考项目省掉的是"摸索画风"的时间，最值钱的是它的**渲染管线**和**建模方式**。

### 2. 每一帧都是时间的纯函数

`renderAt(t)`：给一个时间，算出整帧画面。没有累积状态、没有 `Math.random`（用带种子的随机数）。好处：

- 实时播放和逐帧导出 MP4 是同一份代码，结果一模一样
- 可以跳到任意时间截图检查，修 bug 不用从头播
- 声音用音频时钟驱动画面，音画永远对齐

### 3. 画风来自后期管线，不是来自模型精度

```
场景 → MRT（颜色 + 法线/深度/材质ID）
     → 背景水彩笔触（各向异性 Kuwahara，只作用在"绘制"像素上）
     → 描线（材质 ID 变化、深度跳变、法线转折处画线，带笔压噪声）
     → 大气（海雾、水下光柱、闪光）
     → 泛光 → 调色、胶片颗粒、速度线
```

角色用"赛璐珞"材质：两色硬阴影（阴影偏冷紫）、一块硬高光、边缘光。**材质 ID 决定哪里描线**，这是动画感的关键开关。

### 4. 动作节奏像手绘

角色"一拍二"（每秒 12 张），水花特效"一拍三"（每秒 8 张）。这比 60fps 的丝滑更像动画。

### 5. 分镜表驱动一切

`shots.js` 里写剧情节拍（cue）和镜头表；`director.js` 根据当前时间给出相机、角色姿势、表情、特效发射器。改剧情只改这两个文件。

### 6. 声音交给并行子 Agent

配乐和音效是一个独立的"部门"：给它节拍表（cue 时间点），它用纯 JS 写合成器（卡林巴、弦乐、太鼓、铜管、鲸歌、浪、棘轮……），输出立体声采样。主 Agent 同时做画面，互不阻塞。

### 7. 巨物/角色建模：在"静止姿态"里雕刻，在 GPU 上弯曲

这是第二轮"建模太粗糙"反馈后最重要的一步：

- 身体在静止姿态里建一次：宽度、背高、腹深各一条关键帧曲线，截面是超椭圆
- 在截面上"雕刻"：背脊、三条侧棱、眉骨、眼窝、唇褶、鳃裂、肩部隆起，都是真实几何
- 下颌沿唇线切开，顶点带"下颌权重"，可以真的张嘴；嘴里有口腔
- 鳍、藤壶、䲟鱼、眼球都是独立几何，挂在同一套骨骼上
- 顶点着色器沿脊椎（Catmull-Rom 骨骼）弯曲整条身体，所以 5 万个顶点也不费 CPU
- 皮肤花纹在片元着色器里画，用凹凸法线让明暗交界线碎开，看起来有肉感

### 8. 天空：云是"一组团块的并集"

每团云单独打光会出现一排排一模一样的月牙阴影（第一版的问题）。改成：一座云塔是一个整体光照体积，团块只负责轮廓和凹凸，底部和背光面压淡紫色。

### 9. 交付

- esbuild 把 three.js 和所有代码打成**一个 HTML**
- puppeteer 打开 HTML，逐帧调用 `renderAt`，截图喂给 ffmpeg，和合成好的 WAV 一起编码成 MP4
- 封面也是从片子里直接渲染的帧，标题用代码画（不用生图，保持"100% 代码"）

## 质量控制：真正决定成片水平的部分

1. **每一轮都出接触表（contact sheet）**：12-18 张关键帧拼一张图，自己当美术总监挑刺
2. **关键镜头看全分辨率，可疑处放大看**：锯齿、噪点、穿模都要放大才看得到
3. **调试颜色输出**：怀疑某个参数（比如"每像素多少米"）不对时，直接把它输出成颜色看
4. **跳帧检测脚本**（`tools/pops.mjs`）：逐帧找"某块区域突然大变"的地方，排除切镜，自动揪出瞬移、穿帮
5. **性能脚本**（`tools/perf.mjs`）+ 启动时预编译所有着色器，避免第一次出现某个效果时卡顿

## 踩过的坑（问题 → 原因 → 解法）

| 现象 | 原因 | 解法 |
|---|---|---|
| 云上一排排一样的月牙阴影 | 每团云单独打光 | 整座云塔一个宏观法线，团块并集着色 |
| 巨兽像一根圆柱 | 一根管子沿曲线扫掠 | 截面曲线 + 雕刻 + 真实的鳍 + GPU 蒙皮 |
| 远景皮肤闪烁、有噪点 | 亚像素的花纹、凹凸、高光 | 按"每像素多少米"淡出细节 |
| 斑点被拉成长条 | 网格密度随位置变化 | 两层固定密度网格，靠半径渐变过渡 |
| 水花像一颗颗鸡蛋 | 每个粒子都描边 | 同一团水只描外轮廓；按高度从海蓝过渡到白 |
| 大块纯白、看着像奇怪的云 | 雾团没有阴影；正面受光的云没有暗部 | 雾团加淡紫背光面；正光云底保留阴影 |
| 倒下像一块木板 | 整条身体绕一个点刚体旋转 | 头部滞后（脊柱弯曲甩头）、翻身、鳍乱拍、尾巴甩 |
| 帽子瞬间戴到头上 | 状态直接切换 | 接住 → 抛起翻转 → 落头压扁回弹，全程连续 |
| 水下镜头穿到水面上 | 相机偏移跟着模型尺寸变了 | 相机位置按世界坐标限制 |

## 人怎么参与

人给的是**感觉层面**的反馈就够了：「建模粗糙」「没有活物感」「有一大块全白」「帽子瞬移」。Agent 负责把感觉翻译成具体原因，再自己截图验证。每一轮的固定流程：

```
截图核对问题 → 找到真正原因 → 改 → 全片接触表 + 跳帧扫描 → 重新渲染 MP4 → 抽帧确认
```
